# 01 — MC layer: assembly, encoding, and disassembly

Land a complete assembler/disassembler before code generation. The MC layer is
the single encoding authority shared by hand assembly, compiler output, and
debug tools.

## Checklist

What → Structure → Min test → Done when.

---

- [ ] **Target registration and MC factory**

  **What:** Register SM83 with LLVM target initialization and construct
  MCAsmInfo, MCInstrInfo, MCRegisterInfo, MCSubtargetInfo, code emitter, asm
  backend, object writer, and disassembler.

  **Structure:**
```text
LLVMInitializeSM83TargetInfo
LLVMInitializeSM83Target
LLVMInitializeSM83TargetMC
LLVMInitializeSM83AsmParser
LLVMInitializeSM83Disassembler
```

  **Min test:**
```text
llvm-mc --triple=sm83-unknown-none --version lists target
empty input assembles without a factory/null crash
```

  **Done when:** every MC tool can instantiate SM83 through normal registries.

---

- [ ] **Physical registers and classes**

  **What:** Describe `A F B C D E H L SP PC` and legal pairs. Model overlapping
  8/16-bit registers carefully so allocation/liveness later understands that
  writing BC changes B and C. PC is generally not allocatable; F is flags.

  **Structure:**
```text
8-bit data: A B C D E H L
flags:      F
pairs:      AF BC DE HL
special:    SP PC

subregister relations:
  BC ↔ B:C, DE ↔ D:E, HL ↔ H:L, AF ↔ A:F
```

  **Min test:**
```text
TableGen register-info tests show expected aliases/subregisters
assembler accepts legal register operands and rejects illegal pairs
```

  **Done when:** generated register info expresses every overlap used by the ISA.

---

- [ ] **Instruction definitions and encodings**

  **What:** Define all base and CB-prefixed instructions in TableGen, including
  operand forms, byte size, encoding, implicit flags, and control-flow metadata.
  Undefined opcodes must have no instruction definition.

  **Structure:**
```text
families:
  loads / 16-bit loads
  ALU / flags
  branches / calls / returns / RST
  stack
  CB rotate/shift/BIT/RES/SET
  EI/DI/HALT/STOP

metadata:
  mayLoad, mayStore, isBranch, isCall, isReturn, defs/uses F
```

  **Min test:**
```text
one encoding test per pattern family
generated coverage check accounts for all legal base + 256 CB encodings
```

  **Done when:** encoding coverage matches SoftGBC’s legal opcode set with no
  collisions or undefined entries.

---

- [ ] **Canonical assembly syntax**

  **What:** Choose one documented syntax for registers, immediates, conditions,
  memory operands, comments, and numeric literals. Accept useful aliases only
  when they print back to one canonical form.

  **Structure:**
```text
examples:
  ld a, $2a
  ld [hl+], a
  jr nz, label
  bit 3, [hl]

printer:
  deterministic lowercase mnemonic/registers
  one canonical memory delimiter and hex format
```

  **Min test:**
```text
parse → print → parse gives identical instruction/bytes
bad condition/register/operand count gives location-aware diagnostic
```

  **Done when:** syntax reference and MC tests agree; compiler output is accepted
  by the same parser.

---

- [ ] **Immediate expressions, labels, and fixups**

  **What:** Support absolute 8/16-bit values and PC-relative 8-bit branches with
  fixups. Range checking happens after layout when necessary and diagnostics
  identify the source expression.

  **Structure:**
```text
fixups:
  abs8
  abs16 little-endian
  pcrel8 from address after instruction

validation:
  unsigned/signed range per operand
```

  **Min test:**
```text
forward/backward JR labels encode correctly
JR just inside limits succeeds; one byte outside fails
16-bit symbol emits relocation in object mode
```

  **Done when:** local labels and relocatable symbols share tested fixup logic.

---

- [ ] **Code emitter and assembler backend**

  **What:** Emit exact opcode/immediate bytes and apply resolved fixups in
  little-endian order. Instruction size must be available to layout and debug
  machinery.

  **Structure:**
```text
MCInst + operands
  → opcode pattern
  → immediate bytes / fixups
  → 1, 2, or 3 output bytes
```

  **Min test:**
```text
llvm-mc -show-encoding checks representative and exhaustive generated cases
byte output matches SoftGBC fixtures/opcode table
```

  **Done when:** all legal instructions have exact byte tests.

---

- [ ] **Disassembler**

  **What:** Decode base and CB instructions, immediates, and relative targets.
  Invalid bytes return a defined failure/`.byte` path without consuming an
  incorrect length.

  **Structure:**
```text
read primary
  $CB → require/read second byte → CB table
  otherwise → base table + required immediates
```

  **Min test:**
```text
all legal encodings disassemble to canonical syntax
truncated 2/3-byte instruction reports failure safely
undefined primary byte does not desynchronize following bytes
```

  **Done when:** exhaustive assemble→disassemble→assemble bytes are identical.

---

- [ ] **MC diagnostics and regression suite**

  **What:** Agents and humans need actionable diagnostics. Test unknown
  mnemonics, wrong registers, impossible memory forms, immediate overflow,
  branch range, duplicate labels, and unsupported syntax.

  **Structure:**
```text
diagnostic:
  file:line:column
  invalid token/operand
  expected form or range
```

  **Min test:**
```text
one negative lit test per diagnostic family with CHECK anchors
```

  **Done when:** invalid assembly never crashes/asserts and errors identify how
  to fix the source.
