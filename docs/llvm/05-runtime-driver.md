# 05 — Clang target, compiler runtime, and installed toolchain

Make the backend usable without hand-writing `llc` pipelines. This layer
provides frontend types/macros, runtime helpers, startup objects, linker defaults,
and an installable sysroot consumed by the GBC SDK.

## Checklist

What → Structure → Min test → Done when.

---

- [ ] **Clang target information**

  **What:** Add SM83 target info with the type widths/alignments from
  [`00-contracts.md`](00-contracts.md), target defines, register names for inline
  asm, and the supported language-feature policy.

  **Structure:**
```text
predefines:
  __sm83__
  __SM83__
  __BYTE_ORDER__ little-endian
  freestanding target indicators

types:
  int16, long32, pointer16, size_t16
```

  **Min test:**
```text
clang -target sm83-unknown-none -dM -E
Clang sizeof/alignof CodeGen tests
unsupported TLS/atomics/varargs diagnostics as designed
```

  **Done when:** Clang emits the exact target DataLayout and expected macros.

---

- [ ] **Driver and tool invocation**

  **What:** Teach the Clang driver to select SM83 assembler/linker behavior,
  pass CPU options, locate the sysroot, and produce useful verbose commands.
  Avoid source-tree-relative runtime paths.

  **Structure:**
```text
clang --target=sm83-unknown-none --sysroot=<installed> \
  -ffreestanding -c game.c

clang ... game.o -Wl,-T,<profile-script> -o game.elf
rom packer game.elf + manifest → game.gbc
```

  **Min test:**
```text
-### test checks cc1, assembler/object, LLD, and library search arguments
installed toolchain works from outside repository
```

  **Done when:** one documented driver path replaces manual `llc`/`llvm-mc`
  chaining for normal users.

---

- [ ] **Compiler runtime helper ABI**

  **What:** Implement only helpers generated by legalization: wide shifts,
  multiply/divide/modulo, comparisons, and memory operations as needed. Use
  stable names/signatures and test each helper independently.

  **Structure:**
```text
runtime/compiler-rt:
  integer multiply/divide/mod
  wide shifts
  selected i32/i64 support
  memcpy/memmove/memset primitives

generated code → named helper → normal SM83 ABI
```

  **Min test:**
```text
boundary and randomized vectors compare helper result against host reference
divide-by-zero behavior is documented
overlap test for memmove
```

  **Done when:** no compiler-generated undefined symbol exists for supported C.

---

- [ ] **Startup objects**

  **What:** Provide a minimal freestanding `crt0` that establishes SP, copies
  `.data`, clears `.bss`, initializes SDK hardware policy through a hook, calls
  `main`, and handles an unexpected return deterministically.

  **Structure:**
```text
reset entry:
  disable interrupts
  SP = __stack_top
  copy __data_load → __data_start..end
  zero __bss_start..end
  call __gbc_platform_init
  call main
  call __gbc_exit / halt loop
```

  **Min test:**
```text
initialized global has ROM value
BSS begins zero
stack canary remains intact
return from main reaches documented exit path
```

  **Done when:** C program needs no handwritten assembly to start.

---

- [ ] **Minimal freestanding headers**

  **What:** Supply compiler-facing headers (`stdint.h`, `stddef.h`, `stdbool.h`,
  `limits.h`) consistent with the ABI. Keep device/game APIs in the SDK, not in
  Clang resource headers.

  **Structure:**
```text
Clang resource/sysroot include:
  scalar type and limit definitions

GBC SDK include:
  hardware/runtime/game APIs
```

  **Min test:**
```text
static assertions for every typedef/limit
headers compile as C11 freestanding
```

  **Done when:** basic C source includes standard integer/size headers with no
  host-header leakage.

---

- [ ] **Sysroot layout and profiles**

  **What:** Install headers, crt objects, compiler runtime, linker scripts, and
  SDK libraries in a versioned target sysroot. Profiles select ROM32/MBC5 and
  debug/release policy without changing the target triple.

  **Structure:**
```text
<sysroot>/
  include/
  lib/sm83-unknown-none/
    crt0.o
    libclang_rt.builtins-sm83.a
    libgbc.a
    ldscripts/gbc-rom32.ld
    ldscripts/gbc-mbc5.ld
```

  **Min test:**
```text
install to temporary prefix
compile/link SDK smoke from a separate directory using only prefix
```

  **Done when:** no build command references repository-private object paths.

---

- [ ] **Reproducible toolchain wrapper**

  **What:** Expose one SDK-facing build driver (for example `gbc-clang` or
  `gbc build`) that pins triple, sysroot, linker profile, packer, and map output.
  Agents should not need to reconstruct twenty flags.

  **Structure:**
```text
gbc build --profile gbc-rom32
  → compile
  → archive/link
  → pack/validate
  → game.elf + game.gbc + game.map
```

  **Min test:**
```text
paths containing spaces work
verbose mode prints reproducible underlying commands
two clean builds have identical ROM SHA-256
```

  **Done when:** the SDK can treat the compiler toolchain as one deterministic
  service.
